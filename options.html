How your data is used

When you start a Jira timer, the extension reads only the issue fields needed by your description template and sends the resulting timer description and selected defaults to Toggl. The token and settings stay in this Chrome profile. Nothing is sent to the extension developer.

Daily use

1

Open an issue or select one from a Jira board or backlog.

2

Click the floating Start in Toggl button.

3

Click the same button again to stop that issue timer.

4

For non-Jira work, type a description directly in the extension popup.

Focused permissions

Chrome asks for access only to the Jira site entered above. The Toggl token stays in this Chrome profile and is used only by the extension service worker.

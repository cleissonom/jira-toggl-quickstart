Paste your Jira URL and Toggl token, choose the required Toggl project, then save.

Not configured

How your data is used

The extension reads your Toggl entries for the current browser-local day to show Worked today, and uses your required project ID for every timer it creates. For an identified Jira timer, it reads the issue summary, description, logged time, and estimates to show progress locally. Jira title and description are copied only after you click the copy button. If Work Log sync is enabled, the stopped duration, start time, issue key, and configured comment are sent to your Jira site. Retry records stay in this Chrome profile. Nothing is sent to the extension developer.

Daily use

1

Open an issue or select one from a Jira board or backlog.

2

Click the floating Start in Toggl button.

3

Click the same button again to stop it and optionally create a Jira Work Log.

4

Use the popup to see Worked today, Jira progress, copy Jira details, or retry pending Work Logs.

Focused permissions

Chrome asks for access only to the Jira site entered above. The Toggl token stays in this Chrome profile and is used only by the extension service worker.
